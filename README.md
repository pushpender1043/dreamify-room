# 🛋️ Dreamify Room (AI Interior Designer)

An AI-powered application that redesigns and transforms your room interiors using stable diffusion and advanced generative models.

**🚀 Try it on Google Colab:** [Add Your Colab Link Here] *(Note: Apna Colab ka shareable link yahan zaroor daalna)*

**🛠️ Tech Stack**
* **Language:** Python
* **Framework:** Gradio (for UI)
* **AI Models:** Diffusers, PyTorch, Transformers

**✨ Key Features**
* **Instant Transformation:** Upload a photo of your room and get redesigned concepts instantly.
* **Easy to Run:** Designed to run seamlessly on Google Colab with minimal setup.

**💻 How to Run Locally**
1. Clone the repository: `git clone https://github.com/pushpender1043/Dreamify_Room.git`
2. Navigate to the folder: `cd Dreamify_Room`
3. Install dependencies: `pip install -r requirements.txt`
4. Run the app: `python app.py`
